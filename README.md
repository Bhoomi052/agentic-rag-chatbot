# Agentic AI Chatbot 🚀

This project is a multi-modal AI chatbot with:
- RAG (Retrieval Augmented Generation)
- LangGraph Agents
- Speech-to-Text & Text-to-Speech
- Image Classification

## Tech Stack
- FastAPI (Backend)
- Streamlit (Frontend)
- HuggingFace Models
- FAISS (Vector DB)
